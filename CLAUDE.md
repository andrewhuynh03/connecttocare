# ConnectToCare Project Instructions

## Project goal

Build a portfolio-quality healthcare appointment intelligence system using public or synthetic data. The system should analyze missed appointments, predict no-show risk, and provide a clear dashboard for a clinic coordinator.

## Important boundaries

- Use only public, anonymized, or synthetic data.
- Do not make medical diagnoses or treatment recommendations.
- Present predictions as decision support, not as automatic decisions about patients.
- Document data limitations, fairness risks, and model limitations.

## Technology direction

- Python
- Pandas and NumPy
- Scikit-learn
- SQLite
- Streamlit
- Plotly or Matplotlib
- Git and GitHub

## Development rules

1. Work in small, understandable steps.
2. Before changing files, explain the plan and list the files that will change.
3. Prefer simple code that a student can explain in an interview.
4. Add tests for data transformations and model evaluation.
5. Keep raw data separate from processed data.
6. Never commit credentials, private data, or large raw datasets.
7. Update the README after completing a major feature.
8. After each feature, run the relevant tests and explain the result.

## Suggested milestones

1. Project setup and data dictionary
2. Data ingestion and cleaning
3. Exploratory analysis
4. SQLite schema and loading pipeline
5. Baseline and comparison models
6. Streamlit dashboard
7. Usability testing and revisions
8. Portfolio documentation

## Preferred communication style

Explain technical terms briefly. Show the user the code being changed, why it is changing, and how to verify it.
